# Roll Mod (Minecraft 1.20.1, Forge 47.3.0)

Press **C** to roll (rebind in Options > Controls > Roll).
- Dashes about 3 blocks in the direction you hold (W/A/S/D relative to where you look); no keys = forward.
- Works on the ground and in mid-air.
- Invincible to enemy attacks and projectiles for 0.4s while rolling (not fall damage, fire or lava).
- 2 charges. 1 second between rolls. Each used charge comes back after 3 seconds.
- Rolling animation: the player model somersaults in the roll direction (third person / other players).
  The first-person camera does NOT spin. Charges show under the crosshair when not full.

Build: JDK 17, `gradle build` (Gradle 8.1.1) -> build/libs/rollmod-1.0.0.jar, or use the included GitHub Actions workflow.
